TypeWord · 字里行间
使用指南
版本 0.2.7（2026-10-30）


一、软件简介
------------------------------------------------------------

TypeWord 是一款完全离线运行的本地英语单词学习工具。
主要练习方式为「看中文释义，拼写英文单词」，也可以不看释义，
只听单词读音拼写（听写模式）。界面采用旧式打字机与纸张的风格。

所有词条、学习进度、复习记录和设置都保存在本机 SQLite 数据库
中，不需要账号，不需要联网，也不会向任何服务器发送数据。


二、系统要求
------------------------------------------------------------

- Windows 10 / Windows 11，64 位
- 已安装 Microsoft Edge WebView2 Runtime
  （Windows 10/11 通常已内置；若安装后无法启动，请先从微软官网
  安装 WebView2 Evergreen Runtime）
- 本安装包为 lite 版，约 10 MB（内含离线的六种环境音），
  不携带 WebView2


三、安装
------------------------------------------------------------

1. 双击运行 TypeWord_0.2.7_x64-setup.exe。
2. 按安装向导完成安装。
3. 从开始菜单或桌面快捷方式启动 TypeWord。

安装完成后，本指南也会随程序放在安装目录下的「使用指南.txt」中，
可在程序安装位置随时打开查看。

如果安装时提示文件被占用，请先退出正在运行的旧版程序，再重新安装。


四、覆盖升级与数据继承
------------------------------------------------------------

新版本可以直接覆盖安装，不需要先卸载旧版本。

学习数据保存在用户目录，不在程序安装目录中：

    %APPDATA%\com.typeword.app\typeword.sqlite3

只要仍使用同一个 Windows 用户账户，覆盖安装后词条、分组、
学习进度、复习日志和设置都会自动继承。

注意：
- 升级前建议先导出一次备份。
- 不要通过卸载程序删除数据；卸载时若清除应用数据，数据库会被删除。
- 不要同时运行旧版和新版的多个副本，以免同时读写同一数据库。
- 设置页会显示当前数据库的实际路径，并支持一键复制。


五、快速开始
------------------------------------------------------------

1. 首次启动会自动导入内置初始词库。
2. 打开「今日书桌」，点击开始练习。
3. 在练习入口选择「无尽模式」「复习临期」或「听写模式」。
   练习与听写使用两个独立的出题池：词库中切换「练习池 / 听写池」
   后分别勾选，听写的答题记录与权重不会影响练习进度。
4. 看到中文释义后，在输入框拼写对应英文，按 Enter 提交。
   听写模式不显示释义，会直接播放单词读音，凭听写拼出单词。
5. 答对或答错后都会显示标准答案、拼写提示与复习安排。
6. 答对或揭示答案后，程序会先播完反馈音效，再朗读这个单词。

想先浏览单词而不答题，可点击首页的「翻卡学习」，或使用左侧
导航进入「学习」页面。

首页右侧的单词贴条会随机展示词库中的单词，每 10 秒更换一张，
切换时带翻页动画。首页主标题会与贴条同步换一句随笔，同样每
10 秒一次，两处一起切换。系统开启「减少动态效果」时会改为
瞬时切换。

贴条下方有「朗读单词」与「打开这张词卡」：朗读按钮会直接读
当前贴条上的单词；打开后进入独立的单张词卡页，只展示当前单词
的完整信息，不进入学习模式的翻卡队列。即使它不在已选学习范围
内也能单独查看，翻卡进度不会被打断。贴条轮播或打开词卡时会
停止正在播放的读音。词库只有一个词条时贴条也会继续轮播，不
会停在第一张。

首页与统计页在跨过午夜后会自动刷新“今日”数据；从其他窗口切
回来时也会重新核对日期，不需要手动重新载入。


六、练习操作
------------------------------------------------------------

练习模式
- 每次进入练习，先选择本次的节奏：
  无尽模式：按权重持续随机出题，没有固定终点，适合整段时间练习。
  复习临期：只出已经到复习时间的单词，清完本轮到期的词就结束。
  听写模式：不显示中文释义，自动播放单词读音，只凭听写拼出
  英文；适合做纯听觉检验。当前没有可用英文语音时，这个按钮
  会置灰并提示原因。
- 练习池与听写池分开勾选、分开计算。练习池的权重、复习间隔与
  统计由普通练习共享；听写池有自己的一套权重、正确率与下次复习
  时间，听写答对或答错都不会改动练习池的进度，反之亦然。
- 两个池都受分组开关约束：分组被暂停时，练习和听写都不再出题。
- 入口会分别显示练习池与听写池的可用词数；没有到期词时，复习
  按钮不可点击。
- 练习页右上角「更换模式」可随时回到模式选择页。当前题目会
  保留，点击「返回当前练习」即可继续；选择另一模式则开始新一轮。
  打开模式选择页会立即停止正在播放的读音，并暂停「答对后自动
  下一题」的倒计时；返回当前练习后才恢复。
- 首页「复习到期」与统计页「只练这些错题」会直接进入对应模式，
  不再询问。

提交答案
- 输入完成后按 Enter，或点击「提交答案」。
- 英文大小写不敏感。
- 拼写需要一致，短语中的空格和连字符也要保留。
- 词条可以设置多个可接受答案。

字母提示
- 题目默认展示部分字母，可点击「再提示一个字母」。
- 输入框外按 H 也可以请求额外提示。
- 提示数量有上限；可在设置中关闭字母提示。
- 使用提示后答对，权重下降幅度会小于无提示答对。

我不会
- 点击后立即显示标准答案，并按答错记录。
- 该词会降低权重、缩短复习间隔，稍后再次出现。

跳过
- 按 Esc 或点击「跳过」，本题不计入成绩。
- 被跳过的单词保持作答前的学习状态。

手滑打错了
- 答错后若只是输入失误，可点击「手滑打错了」。
- 本次错误会被撤销，按跳过处理，不计入正确率与复习安排。
- 单词权重和下次复习时间回到作答前状态。

再试一次
- 答错后可点击「再试一次」，重新输入当前单词。

朗读
- 答对或揭示答案（含「我不会」）后，会先播完反馈音效，再朗读
  标准答案；反馈区的小喇叭可随时重播。
- 反馈区的例句旁也有朗读按钮；听写模式会隐藏中文释义，并在
  题目出现后自动播放读音，可用「重播读音」或 S / Ctrl+Space 重播。
- 朗读过程中切换下一题、再试一次、跳过或离开页面，会立即打断
  当前发音；打开「更换模式」页也会立即停止发音并暂停自动跳题。
- 开启「答对后自动下一题」时，自动切换会等反馈音效与朗读都
  结束后再停留约 1.4 秒，不会把发音截断。
- 朗读优先使用 WebView2 提供的本地英文语音；当 WebView2 只能识别
  中文语音时，会自动改用 Windows 传统系统语音（SAPI）中的英文
  语音，例如 Microsoft Zira。两者都找不到英文语音时，朗读入口会
  隐藏并提示安装英文语音包。全程离线，可在设置中关闭。

下一题
- 按 Enter 或点击「下一题」继续。
- 设置中可开启「答对后自动下一题」。

快捷键
- Enter：提交答案 / 下一题
- Esc：跳过当前题
- H：额外提示（输入框外）
- /：聚焦答案输入框
- S 或 Ctrl+Space：重播当前单词读音（输入框外按 S；听写模式
  也可用「重播读音」按钮）


七、学习模式（翻卡）
------------------------------------------------------------

左侧导航「学习」或首页「翻卡学习」进入学习模式。

卡片内容
- 单词、音标、全部中文释义与备用拼写
- 单词旁的「朗读」按钮可随时听发音；例句旁也有独立朗读按钮
- 例句、备注、标签、分类、难度与所属分组
- 学习数据：权重、复习间隔、下次复习、答题次数、正确率、
  连对次数、稳定度、易度、提示次数与最近一次结果

翻页
- 点击卡片，或按 → / ↓ / PageDown / 空格：下一张
- 按 ← / ↑ / PageUp：上一张
- 翻到首尾会循环
- 学习模式会记住最后翻到的那张词卡：切换到练习或其他页面，
  或者关闭软件后再次进入，都会从那张卡继续
- 带有翻页动画与真实翻纸录音，前进与后退音效略有区别；
  可在设置中关闭音效

翻卡声音（右侧面板）
- 「翻卡自动朗读」：每翻到一张词卡，自动读一遍单词。需要系统
  有可用英文语音（WebView2 本地语音或 Windows 系统语音），并在
  设置中开启「单词朗读」。
- 「只听模式」：隐藏释义、例句、标记与学习数据，只保留单词和
  朗读按钮；切换卡片仍会自动朗读。卡片上的「显示完整词卡」可
  临时展开全部内容，「收起完整词卡」可回到只听状态。
- 两个开关都会保存；关闭软件后再进入学习模式仍然生效。
- 语速、口音与朗读总开关在设置页调整。

学习范围
- 点击「选择学习范围」可逐个勾选词条，也可直接点分组名称
  整组选择；支持「全部选中 / 全部取消」和搜索。
- 「未分组」可一次选择所有未归组词条。
- 选择范围独立于练习：某个词可以只出现在翻卡中，也可以只
  参与练习，两者互不影响。
- 分组快捷选择只改变组内词条的学习范围，不会暂停或恢复
  该分组的练习。
- 学习范围旁的撤销提示可在几秒内撤回整组选择，保存期间按钮
  会暂时禁用，避免连续误触。
- 卡片浏览是只读的，不会写入复习日志，也不会改变权重、
  复习时间或正确率。

词卡标记
- 每张词卡下方可以标记「收藏」「稍后再看」「已掌握」。
- 再次点击当前标记即可取消。
- 标记只用于整理词库，不影响抽题、权重和复习安排。
- 词库页面可按标记筛选，并在单词旁显示标记徽标。

翻卡页面右侧会显示当前已选词条数量；没有可翻词条时，可直接
从空白页选择学习范围。

单张词卡页
- 首页贴条下方的「打开这张词卡」进入独立页面，只显示这一张卡。
- 它和学习模式分开：不会加入翻卡队列，也不会改变上次翻到的位置。
- 页面上的标记按钮仍可使用；浏览不会写入复习日志或改变复习计划。
- 单词与例句旁的「朗读」按钮可随时听发音。


八、今日书桌与统计
------------------------------------------------------------

今日书桌会显示今日待复习数量、今日练习情况与当前连续学习天数。
「统计」页面提供正确率、答题总量、待复习数量、最近七天练习量
与错题回顾。

复习预测与保持率
- 「未来七天复习预测」按各词当前的下次复习时间统计每天有多少
  词到期；今天一列包含已经到期和今天到期的词条。
- 「记忆保持率预测」按当前稳定度估算未来七天对每个词的平均
  回忆概率；答对并延长稳定度后，曲线会变得更平缓。
- 两张图只统计当前可练习的词条，与抽题范围一致。

错题重练
- 统计页「答错最多的单词」旁可点击「只练这些错题」，直接进入
  错题重练模式。
- 错题重练会把当时所有答错过的词固定成本组题目，逐个作答，
  不会在同一组里无限循环。
- 完成页会列出本组计划词数、作答数、正确率和“本次仍答错”的
  词；可以只重练本次错题、重练全部错题，或返回书桌。
- 在反馈区点「手滑打错了」会从本次错题组中移除该词。

统计和抽题都只计算当前启用的范围：
- 练习与听写分别勾选：单词在哪个池勾选，才参与哪个池的出题。
- 分组被暂停时，练习和听写都不再出该组单词。
- 暂停或取消勾选不会删除词条，也不会清空学习进度。
- 统计页的答题量与正确率来自复习日志，练习和听写都会记录；
  待复习数量、未来七天预测与记忆保持率按练习池统计。

抽题会优先选择权重较高、遗忘较明显或已经到期的单词，
并避免最近 3 题立刻重复。


九、词库管理
------------------------------------------------------------

进入「词库」页面后可以：

- 新增单词
- 编辑或删除单词
- 按关键词搜索
- 按分类、难度和标记筛选
- 在工具栏切换「练习池 / 听写池」，分别勾选两种模式要出题的单词
- 勾选或取消勾选单词，控制是否参与当前池的练习或听写
- 每行的「朗读」按钮可直接听该词发音
- 在学习模式中给词卡添加「收藏 / 稍后再看 / 已掌握」标记
- 窗口较窄时，操作列的朗读、编辑、删除会自动收为图标按钮，
  避免文字换行挤压表格

词库工具栏的「练习池 / 听写池」开关决定当前列表查看和勾选的是
哪个池：两个池的勾选互不影响，表头也不会串用。切换后，表格里的
当前权重、正确率、下次复习与答题次数都会显示对应池的数据。

词库列表默认只显示「当前池已勾选且所在分组未暂停」的单词，
工具栏的「只看勾选」按钮会显示当前池的勾选数量。点击即可切换为
全部词条，再点一次恢复默认。取消勾选或暂停分组后，该词会立即
从默认列表移出；需要重新勾选时，先切换到全部词条视图。若筛选
结果里的词都因分组暂停而不出题，空白页会直接说明原因。

新增词条至少需要：
- word：英文单词或短语
- meanings：至少一个中文释义

可选字段包括：
- acceptedAnswers：其他可接受的英文答案
- category：分类，默认「核心词汇」
- difficulty：难度 1–5，默认 2
- phonetic：音标
- exampleSentence：例句
- notes：备注或词形变化
- tags：标签

编辑词条不会重置该词的学习进度。


十、练习分组
------------------------------------------------------------

在词库页面顶部可以新建练习分组。

- 分组左侧的复选框控制整组是否参与出题，练习与听写同时生效。
- 取消勾选可暂停整组，重新勾选即可恢复；组内单词各自的池勾选
  会保留，恢复分组后按原勾选重新出题。
- 点击分组右侧的 + 可以批量加入或移出单词。
- 删除分组只会取消分组归属，组内词条与学习进度都会保留。
- 一个单词只能属于一个分组；移入新分组会同时离开原分组。

分组只影响出题范围，不会改变单词本身的学习数据。


十一、批量导入与导出
------------------------------------------------------------

导入
- 在词库页或设置页点击「导入 JSON」。
- 导入按钮旁的 ? 提供完整字段说明和示例。
- 支持两种根节点写法：
  1. 直接使用单词数组
  2. 使用包含 words 数组的对象
- 每条记录单独校验，非法记录会被跳过，并在导入结果中说明原因。
- 可选字段 studyEnabled 控制是否出现在学习模式，默认 true；
  它与练习勾选（enabled）相互独立。
- 可选字段 dictationEnabled 控制是否加入听写池，默认 true；
  字段缺失时沿用练习勾选状态。
- 可选字段 dictationState 保存听写池的独立进度；老版本导出的
  文件没有该字段时按新词导入。更新同名单词的练习进度时，程序
  会保留本机现有的听写池勾选与状态，避免普通备份覆盖听写进度。

导入前会询问是否新建分组：
- 勾选「创建新分组并放入」并填写分组名称后，本次新增的词条
  会自动加入该分组。
- 已存在的词条不会被移入新分组，原分组和学习进度保持不变。
- 不填写分组也可以正常导入。

导出
- 词库页和设置页都可以导出 JSON。
- 导出包含词条、练习勾选、学习范围、词卡标记、权重、复习间隔、
  答题次数和下次复习时间，以及听写池的勾选与独立学习状态。
- 导出不包含分组名称与分组归属，换机后需要重新分组。


十二、数据备份与迁移
------------------------------------------------------------

自动备份快照
- 桌面版每天首次启动时，会自动把当前数据库快照保存到：

  %APPDATA%\com.typeword.app\backups\

- 文件名形如 typeword-backup-2026-10-29.sqlite3。
- 每日自动快照只保留最近 12 份，更早的会自动清理。
- 设置页「本地备份快照」可点击「立即备份」生成手动快照；手动
  备份不会被自动清理。
- 在列表中点击「恢复」可选择某份快照覆盖当前数据。恢复前程序
  会先自动生成一份 pre-restore 安全快照，恢复完成后自动重新载入。
- 自动备份只覆盖数据库内容；若备份目录被手动删除，从下一次启动
  起会重新生成。

其他备份方式：
1. 打开设置页，点击「导出全部数据」，保存 JSON 备份文件。
2. 如需完整备份（包括分组），先退出 TypeWord，再复制数据库文件：

   %APPDATA%\com.typeword.app\typeword.sqlite3

迁移到新电脑：
1. 在新电脑安装相同或更新版本的 TypeWord。
2. 退出程序。
3. 将备份的 typeword.sqlite3 放回新电脑的同一路径。
4. 重新启动程序。

JSON 导入带进度字段的备份时，会覆盖同名单词的学习状态；
分组信息需要重新建立。

可调整的选项包括：

- 显示字母提示
- 答对后自动下一题
- 每日目标
- 默认分类
- 默认难度
- 打字机音效与音量（学习模式的翻页声也受此开关控制）
- 单词朗读：总开关，控制练习、词卡、词库与听写模式中的朗读

- 朗读音量：只影响系统语音，不影响打字机音效
- 语音口音：自动（优先美音）、美音 en-US 或英音 en-GB；系统
  没有对应口音时会自动回退到其他英文语音
- 环境音：内置雨声、咖啡馆、壁炉、鸟鸣、夏夜虫鸣与风声六种

  「环境音」区域选择音源、单独调节音量或关闭。环境音与打字机
  音效、朗读音量互不影响，切换页面不会中断，切换或关闭时会
  自动淡入淡出；重启后会尝试恢复上次选择。若首次播放没有声音，
  点一下窗口任意位置即可解锁

数据与备份区域提供：
- 数据库位置与复制路径
- 本地备份快照列表：立即备份、查看文件名/时间/大小、恢复
- 导出全部数据
- 导入 JSON
- 恢复初始词库（只补入缺失词条，不重置已有进度）
- 重置学习进度（会清除全部答题统计与复习日志，操作不可撤销）

「关于」页显示的版本号与安装包版本一致，由构建时的程序版本

十四、常见问题
------------------------------------------------------------

问：安装后无法启动，或窗口空白。
答：确认系统已安装 WebView2 Runtime。Windows 10/11 一般已内置；
    若缺失，请安装微软官方 WebView2 Evergreen Runtime 后重试。

问：需要联网或登录吗？
答：不需要。程序完全离线运行，没有账号、云同步和在线 API。

问：升级后学习进度会丢失吗？
答：不会。只要使用同一个 Windows 用户账户并覆盖安装，数据会从
    %APPDATA%\com.typeword.app\typeword.sqlite3 自动继承。

问：卸载后重新安装，数据还在吗？
答：如果卸载时删除了应用数据，数据库会被一起删除。卸载或重装前
    请先导出 JSON，或复制 SQLite 文件。

问：导入失败或部分词条没有导入。
答：检查 JSON 是否为有效格式，以及每条记录是否包含 word 和
    meanings。导入结果会列出被跳过记录的原因。

问：为什么有些单词一直不出现？
答：确认该词在当前模式对应的池里已勾选（练习池或听写池），并
    检查它所在的分组是否被暂停。统计中的「待复习」与复习预测
    只计算练习池当前启用的范围。

问：为什么练习池和听写池的可用词数不一样？
答：两个池分开勾选。词库工具栏切换到哪个池，列表里的复选框就
    只改哪个池；另一个池的勾选与学习进度保持不变。

问：听写答错会影响练习的权重和复习时间吗？
答：不会。听写有独立的权重、正确率与下次复习时间。同一单词在
    练习池和听写池各有一套进度，词库切换池后可以分别查看。

问：取消勾选分组后，为什么「只看勾选」列表里也看不到组内单词？
答：分组暂停对练习和听写同时生效，所以默认列表会把整组排除。
    切到全部词条仍能看到并编辑这些单词，重新勾选分组即可恢复出题。

问：学习模式里为什么没有某个单词？
答：学习范围与练习勾选相互独立。进入「学习」页面，点击「选择
    学习范围」，确认该词或它所在的分组已被选中。

问：翻卡会改变学习进度吗？
答：不会。学习模式只展示信息，不写入复习日志，也不改变权重与
    复习安排。

问：为什么答对后没有自动进入下一题？
答：在设置中开启「答对后自动下一题」。

问：没有声音。
答：检查设置中的「打字机音效」和音量。音效文件缺失时程序会尝试
    使用 Web Audio 合成短音，不会影响答题。

问：选择了环境音但没有声音。
答：确认侧边栏「环境音」中已选中音源、环境音音量不为 0。环境音
    与「打字机音效」是两个独立开关。若首次选择后没有声音，点一下
    窗口任意位置即可解锁播放；重启后程序会尝试恢复上次的环境音。

问：单词没有朗读，或发音不自然。
答：确认设置中「单词朗读」已开启，并检查朗读音量与语速。程序
    优先使用 WebView2 能识别的本地英文语音；如果 WebView2 只能
    识别中文，会自动改用 Windows 系统语音（SAPI）中的英文语音。
    设置页在改用系统语音时会显示说明。两种后端都没有英文语音
    时，各处朗读按钮会隐藏，开关会置灰；可在 Windows「设置 →
    时间和语言 → 语音」中添加英文语音包，安装后重新启动程序。
    声音会随语音包不同，设置页还可切换美音 / 英音或调整语速。

问：为什么设置页提示「已自动改用 Windows 系统语音（SAPI）」？
答：部分电脑的 WebView2 只能列出中文语音，即使 Windows 里装有
    英文语音也读不出来。程序会自动改由 Windows 传统语音接口
    朗读，常见音色如 Microsoft Zira，无需联网，也无需重装程序。

问：为什么听写模式按钮不可点击？
答：听写模式依赖系统英文语音。请确认设置中「单词朗读」已开启，
    且 WebView2 或 Windows 系统语音至少有一种英文语音；模式
    选择页底部会给出提示和前往声音设置的入口。

问：安装时提示文件被占用。
答：先退出正在运行的 TypeWord，再重新运行安装包。

问：恢复备份后当前进度会被覆盖吗？
答：会。恢复会用备份内容覆盖当前词库、分组、学习进度与复习
    日志。恢复前程序会自动生成一份 pre-restore 安全快照，完成后
    自动重新载入；如不确定，请先点击「立即备份」。

问：自动备份保存在哪里？会占很多空间吗？
答：位于 %APPDATA%\com.typeword.app\backups\。每日快照只保留
    最近 12 份，手动备份不会自动清理，可随时在设置页查看大小。

十六、数据与隐私
